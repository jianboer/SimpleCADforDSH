## 2. 优先级排序及理由



#### 高优先级

1. US01（文本描述生成 CAD） - 优先级：高
   - 理由： 文本输入是最基础、最高频的交互方式。它是实现 G1（文本/单多视角生成）最核心的第一步。同时，尽早打通“自然语言→工程参数→CAD引擎”的全链路，能最早验证本项目的最大技术风险点，为后续图像生成提供参数映射和建模脚本的复用基础。
2. US05（文本检索相似 CAD） - 优先级：高
   - 理由： 自然语言检索是实现 G2（文本/图像检索）的基础。资产检索复用是项目的核心业务价值之一，且文本检索的技术路径（向量化+标签匹配）相较于图像检索更成熟，适合作为检索模块的第一个突破口，尽早与生成模块进行联调。
3. US02（单视角图像生成 CAD） - 优先级：高
   - 理由： 单图生模是多模态扩展的核心能力。虽然技术风险较高，但这是达成 G1“单多视角 image 生成”的关键一环。在迭代1完成文本生成的基础后，必须尽早引入图像生成，以验证多模态大模型在实际CAD生成中的稳定性和可行性。

#### 中优先级

1. US06（单张图像检索相似 CAD） - 优先级：中
   - 理由： 单图检索是对文本检索能力的补充，实现 G2 的另一半目标。但它的技术实现依赖检索基础设施（如向量库）的搭建，可以基于文本检索的底层架构扩展。在文本检索跑通后再接入图像检索，能有效降低初期同时攻克两个检索模态的并发风险。
2. US03（多视角图像生成 CAD） - 优先级：中
   - 理由： 多视图生成是高阶需求，能显著提升生成成功率（特别是复杂零件），但需要更多的图像预处理和特征融合逻辑。在单图生成（US02）验证通过之前，直接开发多图融合风险过大，因此排在单图生成之后。
3. US07（多张图像检索相似 CAD） - 优先级：中
   - 理由： 与US03类似，多图检索依赖于单图检索（US06）的技术沉淀。多图一致性判别逻辑容易引入误报，需要更多联调时间，放在稍靠后的位置完善更为稳妥。

#### 较低优先级

1. US08（查看检索模型溯源信息） - 优先级：较低
2. US09（查看检索模型规格信息） - 优先级：较低
3. US10（查看检索模型版本信息） - 优先级：较低
   - 理由： 这三个用户故事主要服务于检索结果的信息呈现，属于 G2 目标的附属部分。在核心的检索算法（US05-07）尚未稳定返回准确结果前，展示溯源、规格、版本等详细数据没有实际意义。它们可以在检索的核心排序功能稳定后统一实现。另外，三者均涉及UI展示和元数据接口，常可合并为一个大的前端任务去完成，故事点估算也较低（各3点），适合作为迭代1末期的收尾完善工作。

## 2. 优先级排序及理由

### 高优先级

1. **US11（模型几何合法性检查）——优先级：高**
   - 理由：安排在迭代1中实现。几何合法性是模型后续使用的基础，也是G3质量检查的核心。优先接通模型读取与QA报告，识别非单一实体、几何不封闭等问题，避免不可用模型进入后续流程；同时验证报告反映编辑后的最新状态，为尺寸检查和整体联调提供共用接口。
2. **US12（模型尺寸符合性检查）——优先级：高**
   - 理由：模型几何有效后，还需确认尺寸符合设计要求。外形尺寸、孔径及公差直接影响零件可用性，安排在迭代1中与几何检查共同实现并交付。目标尺寸、公差规则和测试样例可与US11并行准备，在共用接口可用后完成尺寸比对、超差提示及边界值验证。
3. **US23（导出 STEP 文件）——优先级：高**
   - 理由：STEP导出是模型在外部CAD软件中继续使用的关键，也是项目目标中“STEP可由FreeCAD打开”的直接验收项。安排在迭代3中实现，在该迭代内优先接通当前有效模型的导出入口，验证文件与模型一致，并完成FreeCAD打开与几何一致性检查，降低最终交付的兼容风险。

### 中优先级

1. **US24（导出 STL 文件）——优先级：中**
   - 理由：STL导出用于在支持网格模型的软件中使用当前模型，是约定交付格式之一。安排在迭代3中实现，复用前两个迭代形成的模型与QA链路，重点验证文件能够读取、主要外形保持一致，以及无有效模型时不生成空文件；可与GLB导出并行完善，在本迭代内完成正式验收。
2. **US25（导出 GLB 文件）——优先级：中**
   - 理由：GLB导出用于在三维查看环境中展示模型，支撑最终演示和结果分享。安排在迭代3中实现，复用现有GLB输出与预览链路，验证文件加载、主要几何结构一致性及无模型提示；可与STL导出并行完善，在本迭代内完成正式验收并纳入G5端到端演示。

## 2. 优先级排序及理由

### 高优先级

1. **US13（修改模型关键尺寸参数）** — 优先级：高

   - 理由：参数化编辑是后续重新生成模型的前提。AT13-01 至 AT13-04 同时覆盖正常修改和异常输入，适合优先打通参数读写、校验与保存链路。

2. **US14（根据当前参数重新生成模型）** — 优先级：高

   - 理由：该故事让参数真正作用于三维几何，是参数化设计闭环的核心。AT14-01 至 AT14-04 涉及 CAD 内核重建、无效几何拦截和有效模型保护，技术风险高，应尽早验证。

3. **US15（创建二维矩形轮廓）** — 优先级：高

   - 理由：二维轮廓是后续拉伸生成实体的基础。AT15-01 至 AT15-02 虽较简单，但属于从零建模的起点，应优先实现。

4. **US16（拉伸轮廓生成实体）** — 优先级：高

   - 理由：拉伸是二维到三维的关键步骤。后续开孔、圆角、倒角、布尔并集均依赖基础实体，AT16-01 至 AT16-02 是三维建模链路中的必要环节。

5. **US17（创建贯穿孔）** — 优先级：高

   - 理由：贯穿孔是常见安装孔设计特征，属于基础实体建模后的高频操作。AT17-01 至 AT17-02 要求中心定位、贯穿生成和无效参数拦截，应尽早打通。

### 中优先级

1. **US18（执行实体布尔并集）** — 优先级：中

   - 理由：布尔并集属于进阶实体操作，依赖多个实体和 CAD 内核布尔能力。AT18-01 至 AT18-02 包含选择校验和融合结果要求，风险中等，适合基础建模稳定后实现。

2. **US19（创建边圆角）** — 优先级：中

   - 理由：圆角是常见修饰特征，但 AT19-01 至 AT19-04 涉及边选择、半径校验、几何失败和已有孔保留，复杂度较高。应在基础实体和开孔能力稳定后接入。

3. **US20（创建边倒角）** — 优先级：中

   - 理由：倒角与圆角技术路径相似，可复用边选择和几何校验逻辑。AT20-01 至 AT20-03 验收点相对少，适合排在圆角之后实现。

4. **US21（撤销最近一次 CAD 操作）** — 优先级：中

   - 理由：撤销是编辑安全网，能提升操作容错性，但依赖命令历史栈和各类 CAD 操作的集成。AT21-01 至 AT21-02 需要在开孔、圆角等操作稳定后统一接入。

### 较低优先级

1. **US22（查看 CAD 模型树）** — 优先级：较低

   - 理由：模型树主要用于展示建模历史和特征结构，属于辅助可解释性功能。AT22-01 至 AT22-02 需要与特征记录、撤销状态同步，建议在核心建模和编辑能力稳定后作为收尾完善实现。
