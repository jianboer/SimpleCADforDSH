## US07：模型几何合法性检查

**用户故事：** 作为一名初级机械设计人员，我希望查看生成模型的几何合法性检查报告，以便在后续编辑或导出前识别不可用模型。

#### 验收测试用例：

| 编号 | 前置条件与测试数据 | 操作 | 预期结果 |
| ---- | ---------------------- | ---- | -------- |
| AT07-01 | 已生成一个由单一、封闭且有效实体组成的 CAD 模型 | 用户查看该模型的几何合法性检查报告 | 报告的总体结论为“通过”，并显示单一实体和几何封闭性检查均通过 |
| AT07-02 | 已生成一个包含 2 个分离实体的 CAD 模型 | 用户查看该模型的几何合法性检查报告 | 报告的总体结论为“未通过”，明确标记“非单一实体”，并显示实际实体数量为 2 |
| AT07-03 | 已生成一个存在开口或无效几何的 CAD 模型 | 用户查看该模型的几何合法性检查报告 | 报告的总体结论为“未通过”，并明确显示“几何不封闭”或“几何无效”的失败原因 |
| AT07-04 | 同一 CAD 模型在两次检查之间未发生修改 | 用户连续两次查看该模型的几何合法性检查报告 | 两次报告的总体结论和各检查项结果一致，且均可在工作面板中查看 |



## US08：模型尺寸符合性检查

**用户故事：** 作为一名初级机械设计人员，我希望查看模型关键尺寸与设计要求的符合性检查结果，以便在导出前确认模型满足设计要求。

#### 验收测试用例：

每个关键尺寸优先使用设计要求中单独指定的公差；未指定时，使用项目默认公差 0.2 mm。实测值与期望值的偏差小于或等于公差时视为符合要求。

| 编号 | 前置条件与测试数据 | 操作 | 预期结果 |
| ---- | ---------------------- | ---- | -------- |
| AT08-01 | 设计要求为 X=100 mm、Y=80 mm、Z=20 mm、孔径=10 mm，未单独指定公差；模型对应实测值为 100.1 mm、79.9 mm、20.1 mm、9.9 mm | 用户查看该模型的尺寸符合性检查结果 | 所有关键尺寸均按默认公差 0.2 mm 判定为符合要求，总体结论为“通过” |
| AT08-02 | 设计要求为 X=100 mm，使用默认公差 0.2 mm；模型 X 尺寸实测值为 100.3 mm，其他关键尺寸均在公差内 | 用户查看该模型的尺寸符合性检查结果 | 总体结论为“未通过”，报告指出 X 尺寸超差，并显示期望值 100 mm、实测值 100.3 mm、偏差 0.3 mm 和公差 0.2 mm |
| AT08-03 | 设计要求中孔径为 10 mm，使用默认公差 0.2 mm；模型孔径实测值为 10.3 mm，其他关键尺寸均在公差内 | 用户查看该模型的尺寸符合性检查结果 | 总体结论为“未通过”，报告指出孔径超差，并显示期望值 10 mm、实测值 10.3 mm、偏差 0.3 mm 和公差 0.2 mm |
| AT08-04 | 设计要求为 X=100 mm，并为该尺寸单独指定公差 0.5 mm；模型 X 尺寸实测值为 100.5 mm | 用户查看该模型的尺寸符合性检查结果 | 该尺寸使用单独指定的公差 0.5 mm，偏差等于公差，因此判定为符合要求 |
