# PMBOK第六版49子过程裁剪表

本表于2026年11月2日对照任务书完善，按课程指定的第六版口径编制。裁剪不等于宣称过程已完成；“待执行”及“条件执行”均为后续安排，规划项为本次提出的报告组织方式。开发责任沿用八人团队，章节供稿责任按任务书分配。配置管理纳入4.1，不另计为第50个过程。

“本阶段不展开独立概率模拟”仅裁剪定量分析工具深度，不删除该过程；取得可靠分布后再决定是否开展。“条件执行”须有实际采购触发；未知状态不写为已完成。

过程组数量：启动2、规划24、执行10、监控12、收尾1；知识领域数量：整合7、范围6、进度6、成本4、质量3、资源6、沟通3、风险7、采购3、干系人4。
