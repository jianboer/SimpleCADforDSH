# 小组协作

课程项目分为三个开发组：

| 小组 | 主要职责 | 目录 |
| --- | --- | --- |
| 生成、检索组 | text/image-to-CAD、CAD 模型检索及相关 Skills 和 Tools | [`01-generation-retrieval/`](01-generation-retrieval/) |
| FreeCAD 迁移组 | 筛选、重构并迁移 FreeCAD 的基础 CAD 操作能力 | [`02-freecad-migration/`](02-freecad-migration/) |
| 集成组 | 模块接口、联调、测试、调试、发布与演示稳定性 | [`03-integration/`](03-integration/) |

各组在自己的目录中维护计划、设计说明、接口约定和验收记录。影响多个小组的接口或流程，应在本目录记录并由相关小组共同确认。
